## 드래곤 러쉬 PvP 상성 v2 요약 (검토 반영)

**상성 고리**: 검사 → 닌자 → 궁수 → 마법사 → 광전사 → 검사. 각 직업은 고리에서 다음 두 직업을 이긴다.

- **대(大) 상성**: 목표 64%, 허용 60~68.
- **소(小) 상성**: 목표 60%, 허용 56~64.
- **상한**: 합산 셀 68%, 보통·쉬움 층 70%, 어려움 층 75%.

### 직업별 상성과 공격 방식
| 직업 | 유형 | 공격 방식 (리듬 · 사거리) | 특수 방어 | 강함 (대 / 소) | 약함 (대 / 소) | 이기는 이유 | 질 때의 탈출구 |
|---|---|---|---|---|---|---|---|
| **검사** | 결투가·반격 | 1-2-3 연타 후 패링 읽기 · 50~90px | 패링 (반격 / 반사) | 궁수 / 닌자 | 마법사 / 광전사 | 반사(위력 ×0.5)와 대시 환급으로 접근한다. 단검 반격 10.7 | 비전 화살은 흡수되고 메테오는 패링 불가. 대시로 화살을 뚫는다. 불굴 |
| **궁수** | 견제·카이팅 | 당기기 40f 후 발사, 예측 조준 · 250~480px | 당김을 유지하는 뒷걸음 | 광전사 / 마법사 | 검사 / 닌자 | 속도 190 대 165. 완전 사격 넉백(광전사는 절반). 화살 사거리 480 대 비전 화살 360 | 근접전에서 빠른 사격으로 패링을 유도한다. 일제 사격. 완전 사격으로 쿠나이를 파괴한다 |
| **마법사** | 함정·통제 | 시전 → 장전 유지 → 해제, 0.5초 뒤 폭발 · 180~320px | 점멸 (투명) | 검사 / 광전사 | 닌자 / 궁수 | 패링에 쓸 만한 결과가 없다. 메테오가 아머를 깬다. 관통으로 DEF가 절반 | 상대가 행동에 들어간 순간 장전한 메테오를 해제한다. 점멸 직후 비전 화살 |
| **닌자** | 돌진·암살 | 0.2초 2연타 후 이탈 · 0~44px, 쿠나이 ≤ 240px | 그림자 걸음 2충전 (몸 통과) | 마법사 / 궁수 | 광전사 / 검사 | 속도 230. 표식에서 걸어서 탈출(3.83 대 필요 3.4 px/f). 4f 단검이 시전과 당김을 끊는다 | 도끼의 39f 방향 고정 중 등 뒤 찌르기(×1.5). 패링 유도 후 돌진 |
| **광전사** | 저거넛·난타 | 접근해 큰 일격(0.65초), 회오리로 정리 · 0~80px | 슈퍼 아머 + 경직 저항(넉백 절반) | 닌자 / 검사 | 궁수 / 마법사 | 아머가 단검을 무시한다. 도끼 4방(광폭 3방). 분쇄로 반격 없이 패링을 끝낸다 | 어깨 돌진(128px, 쿨 60f). 광폭. 24초부터 좁아지는 불의 고리 |

### v1에서 바뀐 점 (검토 결과)
| 문제 | 심각도 | 수정 |
|---|---|---|
| 빠른 직업이 견제 후 도망쳐 시간 종료 HP 비율로 이긴다(닌자 쿠나이 등). 광전사>닌자, 광전사>검사, 검사>닌자가 뒤집힌다 | 치명 | 불의 고리 24→34초에 반지름 460→160px [결정 필요], 쿠나이 사거리 240px, 퇴화 전략 테스트(A12) |
| 반사 화살이 위력 1.6 그대로라 검사가 서서 패링만 해도 이긴다 | 치명 | 반사 위력 ×0.5, 관통 없음. 대시 환급은 유지해 접근이 보상이 되게 한다 |
| 곧게 나가는 화살은 옆걸음으로 반응 회피된다. 결과가 봇 경로에 따라 달라진다 | 높음 | 궁수 사격 부분 예측 조준(최대 12f) [결정 필요]. 봇은 방향을 바꿔 회피한다 |
| 완전 사격 넉백 48 + 경직 12f가 광전사를 묶어 둔다 | 높음 | 넉백 40, 경직 10f. 광전사 경직 저항 0.5 |
| 용전 부작용: 검사가 반격을 남발하고, 용이 경직되고, 광전사 회피 주기가 부족하다 | 높음 | 패링 결과를 기술별 데이터로 둔다(용 기술은 v1). 용은 경직 면역. 어깨 돌진 쿨 60f 유지. 직업별 용전 기준(A14) |
| 검사·궁수는 약화가 필요한데 버프만 받았다 | 높음 | 검사 마무리 위력 1.5, 궁수 완전 당김 40f |
| 2~4명 판에서는 한 직업이 유리할 수 있다. 공개 순차 선택이면 카운터픽이 된다 | 높음 | 비공개 동시 선택 권장 [결정 필요]. 판 구성별 공정성 기준(A13) |
| 끌어서 조준하는 메테오가 봇 모델과 맞지 않고 마법사를 약화한다 | 중간 | v1 자동 조준 + "장전 메테오"(최대 24f 유지 후 즉시 해제) |
| 화살 패링 시 헛패링 처리(`dispel`)가 함정이 된다 | 중간 | `absorb`: 화살만 무효, 헛패링 경직 없음 |
| 패링 결과 다섯 가지와 아머 프레임이 화면에서 구분되지 않는다 | 중간 | 무기 붉은 섬광, 아머 금속 외곽선, 방향 쐐기 표시, 결과별 효과음 |
| 허용 범위(±2)가 측정 오차(±2.1)와 같다. 어려움 지연(5f)이 초인적이다 | 중간 | 범위를 넓힌다. 기준 행렬은 보통·쉬움만 합산하고 어려움은 따로 본다 |

> 수치는 모두 시작값이다. 확정은 봇 시뮬레이션 루프(§6)와 사람 플레이테스트로 한다. 사용자 결정이 필요한 항목은 D1 소수 HP, D2 스탯 견고성, D6 선택 방식, D7 불의 고리, D8 궁수 예측 조준이다.
